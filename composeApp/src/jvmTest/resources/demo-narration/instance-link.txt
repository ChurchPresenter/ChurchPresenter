intro = Welcome to ChurchPresenter. In this tour, we'll link two computers running ChurchPresenter, so a second room shows exactly what the main room shows.
why = It's made for an overflow room, a fellowship hall, a children's wing, or a second campus. One person runs the service, and the other screens follow along by themselves.
primary = Start on the main computer. Open Settings, and go to the Server page.
server-on = Turn on the companion server with this switch. Once it's on, it says Running.
address = Its address appears right below. That's what you'll type on the second computer.
open = Then, on the second computer, open the Connect menu, and choose Connect to Instance.
host = Type the main computer's address, and the port shown on its Server page. That's 8765 unless you changed it.
api-key = If the main computer uses an API key, enter the same key here.
role = Now choose a role. Controlled shows whatever the main computer shows. That's the one for an overflow room.
controller = Controller works the other way around. This computer drives the main computer's screens, like a second operator in the booth.
layers = Pick which layers to follow: slides and backgrounds, media, lower thirds, captions and announcements.
bible = For the Bible, Full replica uses the main computer's own Bible. Reference only follows the same verse in this computer's Bible, so a second room can show it in another language.
push = Turn on adding items to the primary's schedule, and someone in the second room can send songs to the main schedule.
connect = Click Connect.
connected = Once it's connected, the window shows what the main computer has live, and how many items are in its schedule.
live = Now, whatever goes live in the main room appears here too, at the same moment.
autoconnect = Turn on Connect automatically on launch, and the link comes back by itself every week. If the network drops, it reconnects on its own.
outro = And that's Instance Link: one person runs the service, and every room follows along.
