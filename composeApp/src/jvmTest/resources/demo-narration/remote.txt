intro = Welcome to ChurchPresenter. In this tour, we'll connect the ChurchPresenter mobile app to your computer, so you can run the service from your phone or tablet.
why = With the mobile app, a worship leader or a volunteer can pick songs, show verses and go live from anywhere in the room.
server = First, on the computer, open Settings and go to the Server page.
start = Switch on the Companion Server. It lets phones and tablets on your church network connect to this computer.
qr = Click QR to show the connection code. It holds this computer's address, so nobody has to type it on the phone.
phone-mode = The first time you open the app on your phone, it asks how you'll present. Choose Remote control, so the phone drives ChurchPresenter on your computer.
phone-open = Next, it walks you through connecting to the computer.
phone-scan = Tap the button to scan the QR code, and the camera opens.
scanning = Hold the phone up to the code on the computer screen, and it reads the address in a moment.
phone-manual = If the camera isn't an option, you can type the computer's address and port instead. Both devices need to be on the same Wi-Fi network.
api-key = For extra protection, switch on API Key Protection in the Server settings. Phones then need the key to connect, and the QR code includes it, so scanning still sets everything up.
api-key-phone = If you type the address by hand instead, enter the key in the API Key field.
connected = The phone now shows that the server is connected, along with what this device is allowed to do.
tabs = Across the bottom are the app's tabs: Songs, Bible, Media, Present and More.
tab-songs = Songs has your whole song library, and you can search it by title or number.
tab-bible = Bible lets you pick a book, a chapter and the verses to show.
tab-media = Media plays your videos and audio on the computer, with play, pause and volume right on the phone.
tab-present = Present holds your pictures and presentations.
tab-more = More has everything else, like the calendar, Q and A, the dictionary, announcements and web pages.
uploads = The phone can also send photos and presentations to the computer, like the sermon slides. To let phones upload, switch on Allow File Upload in the Server settings.
uploads-phone = The phone shows the upload as it goes, and the file is ready on the computer when it's done.
schedule = Tap the menu button at the top of the screen to open the schedule. It shows the service you've planned on the computer, in order, with the item that's on screen marked as live.
bible-none = The phone keeps its own Bibles, so verses come up quickly. If none is installed yet, tap Get Bibles.
bible-catalog = Pick a translation from the catalog. You can narrow it down by language and by source.
bible-licence = Before anything downloads, the app shows the translation's copyright and licensing. Only use Bibles your church is licensed to show.
bible-download = The phone downloads the translation and converts it, and then it's ready to use.
bible-pick = Choose which translation to show from the list of Bibles on your phone.
song-open = Now let's put a song on the screen. Go back to the Songs tab.
song-pick = Then tap Amazing Grace to open it.
add = To add the song to the service, tap the add-to-schedule button, the orange one.
send = To put it on the screen right away, tap the present button, the green one below it.
allow = The first time a phone asks to change anything on the computer, the computer asks you first. There are six choices.
perm-block-session = Block for Session refuses everything from this phone until ChurchPresenter closes.
perm-block = Block Permanently refuses this phone from now on. You can undo that under Remote Clients.
perm-deny = Deny turns down just this one request.
perm-session = Allow for Session lets this phone through without asking again, until ChurchPresenter closes.
perm-always = Allow Permanently trusts this phone from now on, even after ChurchPresenter restarts.
perm-allow = And Allow lets just this one request through, so the phone asks again next time.
allow-session = Here, we'll allow this phone for the session.
added = Amazing Grace now appears at the end of the schedule on the computer, ready for the service.
live = The song goes live on the computer right away, without anyone touching the computer. The phone is allowed for this session, so the computer doesn't ask again, and the phone marks the verse that's on screen.
clients = Devices you allow permanently, or block, are listed under Remote Clients in the Server settings, so you can change your mind later.
mirror = The phone can also show what's on the screen right now, so you always know what the congregation sees.
outro = And that's how to connect the mobile app. Turn on the server, scan the code, and run your service from anywhere in the room.
