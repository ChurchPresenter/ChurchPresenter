# The presentation tour's narration in Brazilian Portuguese, key for key with presentation.txt; each line fitted to its slot in the video.

intro = Bem-vindo ao ChurchPresenter. Vamos ver a aba Apresentação, que mostra no telão os slides da pregação, avisos e outras apresentações.
open-tab = Vamos abrir a aba Apresentação.
select-file = Para abrir, clique em Selecionar arquivo. Aceita PowerPoint, Keynote e PDF, então use os slides que já tem.
recents = Os arquivos recentes ficam aqui. Clique duas vezes e os slides carregam. Vamos abrir a pregação de hoje sobre o Bom Pastor.
click-slide = Cada slide aparece em miniatura. Clique num slide e ele vai à prévia, para você conferir.
go-live = Pronto? Clique em Ao vivo, e vai ao projetor.
live-1 = Só o título aparece. Este slide tem animações do PowerPoint, e o ChurchPresenter as toca como foram feitas.
build-first = Seta para a direita: primeira animação.
built-first = O primeiro ponto aparece, como no PowerPoint.
build-second = De novo, para o próximo.
built-second = Surge o segundo ponto.
build-third = E mais uma, para o último.
built-third = Todos os pontos na tela. Você dita o ritmo, um toque por vez.
transition-slide = Após as animações, o próximo toque passa o slide, com a transição do arquivo original.
live-2 = Essa transição veio do PowerPoint, com a animação que traz a referência.
double-click = Um clique duplo num slide pula até ele e põe ao vivo.
live-3 = Agora o slide quatro está no telão.
hide = Quer pular um slide hoje? Clique no olho do cartão para ocultar. Ele fica no arquivo, mas as setas e a apresentação o pulam.
play = Clique em Reproduzir para os slides passarem sozinhos, ótimo para avisos.
interval = Escolha quanto tempo cada slide fica na tela.
transition = A duração da transição define o tempo da troca.
loop = Com Repetir ligado, recomeça após o último slide.
animation = Para slides sem transição própria, escolha como um vira o outro. Abra a lista de transições.
fade = Escolhemos Esmaecer, bem suave.
blank = Precisa escurecer a tela, para uma oração? O botão do olho no topo controla a saída. Clique em Ocultar saída, e ninguém vê nada.
blanked = O projetor está escuro, mas o slide espera embaixo.
unblank = Clique de novo, e o slide volta na hora.
keys = Há atalhos para tudo. A barra de espaço toca e pausa, e a tecla B ou o ponto escurece a tela.
server = O controle remoto usa o servidor do ChurchPresenter, então ligue-o antes. Abra Configurações, página Servidor.
server-enable = Ligue o servidor. É ele que conecta celulares, tablets e outros aparelhos. Ligado, o status muda para Rodando.
server-key = Para mais segurança, ligue a proteção por chave API, e só quem tem a chave conecta.
remote = Agora, algo muito útil. Com o controle remoto, quem prega troca os slides pelo celular ou tablet, no púlpito. Clique em Controle remoto.
remote-enable = Primeiro, ligue Ativar controle remoto. Assim celulares e tablets conectados veem e trocam os slides.
remote-qr = Para conectar um celular, escaneie este QR code. O controle abre no navegador, sem instalar app.
remote-copy = Você também pode copiar o endereço e mandar para quem vai apresentar.
remote-key = O link é protegido pela chave API, então só quem você escolheu controla os slides.
remote-public = Celulares no wi-fi da igreja conectam na hora. E um pregador convidado, ou um celular fora da rede? Para isso existe o Acesso público. Ligue-o, e o ChurchPresenter abre um túnel seguro, para conectar pelos dados móveis. Os links públicos são temporários e mudam a cada túnel novo.
preset = Se usa esta apresentação sempre, salve como predefinição, para pôr em qualquer culto com um clique.
schedule = Para usá-la mais tarde, clique em Adicionar à programação.

clear = E ao terminar, o botão vermelho limpa tudo.
outro = Essa é a aba Apresentação. Abra os slides, deixe as animações rodarem e avance pelo teclado ou celular.
