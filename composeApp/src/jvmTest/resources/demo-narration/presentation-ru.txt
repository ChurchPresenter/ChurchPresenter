# The presentation tour's narration in Russian, key for key with presentation.txt; each line fitted to its slot in the video.

intro = Добро пожаловать в ChurchPresenter. Посмотрим вкладку «Презентация»: слайды проповеди, объявления и другие презентации на большом экране.
open-tab = Откроем вкладку «Презентация».
select-file = Чтобы открыть презентацию, нажмите «Выбрать файл». Поддерживаются PowerPoint, Keynote и PDF, так что подойдут ваши слайды.
recents = Недавние файлы здесь. Дважды щёлкните, и слайды загрузятся. Откроем утреннюю проповедь о Добром Пастыре.
click-slide = Каждый слайд виден миниатюрой. Нажмите на слайд, и он сначала появится в предпросмотре.
go-live = Когда готовы, нажмите «В эфир».
live-1 = Видно только заголовок. В этом слайде есть анимации из PowerPoint, и ChurchPresenter воспроизводит их как задумано.
build-first = Стрелка вправо: первая анимация.
built-first = Появился первый пункт, как в PowerPoint.
build-second = Ещё раз, следующий пункт.
built-second = Вот второй пункт.
build-third = И последний.
built-third = Все пункты на экране. Темп задаёте вы, по одному нажатию.
transition-slide = Когда анимации закончились, нажатие переходит к слайду, с переходом из исходного файла.
live-2 = Этот переход взят из PowerPoint, как и анимация ссылки.
double-click = Двойной щелчок по слайду сразу выводит его в эфир.
live-3 = Четвёртый слайд на экране.
hide = Слайд сегодня не нужен? Нажмите на глаз на карточке, чтобы скрыть его. Он останется в файле, но стрелки и показ его пропустят.
play = Нажмите «Воспроизвести», и слайды пойдут сами, удобно для объявлений.
interval = Выберите, сколько держится каждый слайд.
transition = Длительность перехода задаёт время смены.
loop = С «Повтором» показ начнётся заново.
animation = Для слайдов без своих переходов можно выбрать эффект смены. Откройте список переходов.
fade = Выберем «Затухание», мягко.
blank = Нужен тёмный экран, например на молитву? Кнопка с глазом вверху управляет выводом. Нажмите «Скрыть вывод», и зал ничего не видит.
blanked = Проектор тёмный, но слайд ждёт под ним.
unblank = Нажмите снова, и слайд вернётся.
keys = Для всего есть клавиши. Пробел запускает и ставит паузу, а B или точка затемняют экран.
server = Пульт работает через сервер ChurchPresenter, так что сначала включим его. Откройте «Настройки», страницу «Сервер».
server-enable = Включите сервер. Через него подключаются телефоны, планшеты и другие устройства. Когда он работает, статус «Запущен».
server-key = Для защиты включите API-ключ, и подключатся только устройства с ключом.
remote = А теперь очень полезное. С пультом проповедник листает слайды с телефона или планшета прямо с кафедры. Нажмите «Пульт».
remote-enable = Сначала включите «Разрешить пульт». Подключённые телефоны и планшеты смогут листать слайды.
remote-qr = Чтобы подключить телефон, отсканируйте QR-код камерой. Пульт откроется в браузере, без приложения.
remote-copy = Можно скопировать адрес и отправить тому, кто выступает.
remote-key = Ссылка защищена API-ключом, и слайдами управляют только те, кому вы его дали.
remote-public = Телефоны в церковном Wi-Fi подключаются сразу. А если это гость-проповедник или телефон вне вашей сети? Для этого есть «Публичный доступ». Включите его, и ChurchPresenter откроет защищённый туннель через мобильный интернет. Публичные ссылки временные и меняются с каждым новым туннелем.
preset = Если презентация нужна часто, сохраните её как пресет, и добавляйте в любое служение одним щелчком.
schedule = Чтобы вернуться к ней позже, нажмите «Добавить в программу».
schedule-row = Проповедь уже в программе слева.
clear = А в конце красная кнопка уберёт презентацию.
outro = Вот и вкладка «Презентация». Откройте слайды, пусть играют анимации, и листайте с клавиатуры или телефона.
