intro = Welcome to ChurchPresenter. In this tour, we'll run a whole service from the keyboard, then see where every shortcut lives and how to change one.
why = With your hands on the keys, you never have to hunt for a button while everyone is watching the screen.
f-keys = Each main tab has its own F key: F6 for the Bible, F7 for Songs, F8 for Pictures, F9 for Presentation, F10 for Media, F11 for Lower Third, and F12 for Announcements.
search = In the Songs tab, the search box is ready, so just type the name of the song.
enter = Press Enter, and the highlighted song goes live.
down = The down arrow moves to the next verse.
up = The up arrow goes back one.
f2 = F2 adds the song to the schedule.
reference = Over in the Bible tab, type a reference, like John three sixteen.
bible-enter = Press Enter to put it on the screen.
bible-down = The down arrow shows the next verse.
clicker = Page Down and Page Up move a live presentation forward and back from any tab, so a presentation clicker works too.
escape = When you're done, Escape clears the screen.
open-dialog = To see every shortcut, press F1, or open the Help menu and choose Keyboard Shortcuts. Every key the app uses is listed here, and if you don't like one, you can change it.
categories = The shortcuts are grouped down the left: the menus, the ones that work everywhere, and each tab's own.
managers = The Menus group also opens the managers. Control Shift L opens the Song Library Manager, Control Shift D the Calendar Manager, and Control Shift K the Converter.
search-actions = Type in the search box to find a shortcut by its name.
press-key = Or turn on Press key, then press a combination to see what it does.
rebind = To change a shortcut, click its keys, then press the new combination.
conflict = If that combination is already taken, ChurchPresenter names the shortcut that has it, and won't save until you sort it out.
conflicts-list = The conflicts button at the top counts every clash. Click it to see them all in one list.
fix = To fix it, give the other shortcut a new key. Click the Bible tab's keys, and press F5.
fixed = Now there are no conflicts left, and OK works again.
clear = Clear takes a shortcut's keys away, for one you never want to press by accident.
reset = Reset puts one shortcut back the way it was.
reset-all = Reset All to Defaults puts every shortcut back at once.
save = Click OK to save your changes.
outro = And that's keyboard shortcuts: your whole service, right from the keys.
